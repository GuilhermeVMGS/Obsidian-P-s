# KNN — K-Nearest Neighbors (K-Vizinhos Mais Próximos)

O KNN (K-Nearest Neighbors) é um algoritmo de Machine Learning supervisionado, utilizado principalmente em problemas de classificação e regressão.

Sua ideia central é bastante intuitiva: observações semelhantes tendem a apresentar resultados semelhantes.

Em vez de aprender regras matemáticas complexas durante o treinamento, o KNN utiliza os exemplos conhecidos para fazer previsões sobre novos dados.

1. **Como funciona o KNN:** imagine que temos um conjunto de dados com dois tipos de frutas: maçãs e laranjas. Cada fruta possui características como peso e tamanho. Quando uma nova fruta aparece, o KNN procura as frutas mais próximas dela, considerando essas características.
![[Pasted image 20261105203349.png]]

O funcionamento segue quatro etapas:

1. Definir o valor de K, que representa quantos vizinhos serão considerados.
2. Calcular a distância entre o novo exemplo e os exemplos conhecidos.
3. Selecionar os K exemplos mais próximos.
4. Realizar a previsão com base nesses vizinhos.

Na classificação, vence a classe mais frequente. Na regressão, normalmente calcula-se a média dos valores dos vizinhos.

2. **O que significa o K:** o parâmetro K determina quantos vizinhos o algoritmo considera para realizar uma previsão. 

**K pequeno versus K grande**:
- *K pequeno:* considera poucos vizinhos, tornando o modelo mais sensível a ruídos e outliers. Pode causar overfitting.
- *K grande:* considera mais vizinhos, produzindo decisões mais estáveis, mas podendo ignorar padrões locais. Pode causar underfitting.

Não existe um K ideal para todos os problemas. Normalmente, escolhemos esse valor utilizando validação cruzada.

**Como o KNN calcula as distâncias:** uma das métricas mais utilizadas é a distância euclidiana, que representa a distância em linha reta entre dois pontos.

![[Pasted image 20261105204033.png]]

**KNN para classificação e regressão**

| Classificação                   | Regressão                        |
| ------------------------------- | -------------------------------- |
| Prevê uma categoria             | Prevê um valor numérico          |
| Identificar se um e-mail é spam | Prever o preço de uma casa       |
| Utiliza votação dos vizinhos    | Utiliza média ou média ponderada |

Por exemplo, se os três vizinhos mais próximos de uma casa custam R$ 300 mil, R$ 320 mil e R$ 340 mil, o KNN de regressão pode prever:

![[Pasted image 20261105203608.png]]
Ou seja, R$ 320 mil.

**O KNN realmente aprende?**

Essa é uma característica importante do algoritmo.

O KNN é considerado um algoritmo de aprendizado preguiçoso (Lazy Learning).

Isso significa que ele não constrói um modelo paramétrico explícito durante o treinamento, como acontece na regressão linear. Em vez disso, ele armazena os exemplos de treinamento e realiza os cálculos necessários quando recebe um novo dado.
Por isso, o KNN também é considerado um método não paramétrico e baseado em instâncias.

**Vantagens e desvantagens**

|Vantagens|Desvantagens|
|---|---|
|Simples de entender|Previsões podem ser lentas|
|Fácil de implementar|Pode consumir muita memória|
|Serve para classificação e regressão|Sensível à escala dos dados|
|Não pressupõe uma distribuição específica|Sofre com alta dimensionalidade|

Um ponto fundamental é a normalização ou padronização das variáveis.

Imagine um dataset com idade variando de 18 a 80 anos e salário variando de R$ 1.000 a R$ 50.000. Sem padronização, o salário pode dominar o cálculo da distância apenas porque seus valores são numericamente maiores.

Por isso, técnicas como `StandardScaler` e `MinMaxScaler` são frequentemente utilizadas antes do KNN.

# SVM — Support Vector Machine (Máquina de Vetores de Suporte)

O SVM (Support Vector Machine) é um algoritmo de Machine Learning supervisionado, utilizado principalmente para problemas de classificação, mas também pode ser aplicado à regressão (SVR).

Diferentemente do KNN, que classifica uma nova observação com base nos vizinhos mais próximos, o SVM procura encontrar uma **fronteira de decisão** que separe as classes com a maior margem possível.


**Como funciona o SVM:** imagine que queremos classificar clientes em duas categorias:

- Azul: baixo risco de inadimplência.
- Vermelho: alto risco de inadimplência.

O SVM tenta encontrar uma linha que separe essas duas classes da melhor maneira possível.

![[Pasted image 20261105204436.png]]
A linha verde representa a fronteira de decisão, também chamada de **hiperplano**.
As linhas tracejadas representam as margens. O SVM procura maximizar a distância entre elas, respeitando as restrições e penalidades do modelo.

**O que são vetores de suporte:** os vetores de suporte (Support Vectors) são os pontos de treinamento mais importantes para determinar a posição da fronteira de decisão.

São justamente esses pontos que dão nome ao algoritmo. No gráfico, alguns pontos estão destacados com círculos maiores para ilustrar essa ideia.

Enquanto o KNN considera os vizinhos próximos para cada previsão, o SVM utiliza uma fronteira aprendida durante o treinamento.

**O que é a margem máxima:** iImagine duas linhas diferentes capazes de separar corretamente clientes de alto e baixo risco.

Uma delas passa muito perto dos pontos de ambas as classes. A outra deixa um espaço maior entre os pontos mais próximos e a fronteira.

O SVM prefere, em sua formulação clássica, a segunda opção.

Isso porque uma margem maior pode favorecer a generalização, ou seja, a capacidade de classificar corretamente dados que não foram utilizados no treinamento.

**E quando os dados não podem ser separados por uma linha reta (SVM Não-Linear):** nem sempre os dados são linearmente separáveis. Nesse caso, o SVM pode utilizar uma técnica chamada Kernel Trick (truque do kernel).

# Matriz de Confusão (Confusion Matrix)

A matriz de confusão é uma ferramenta utilizada para avaliar o desempenho de modelos de Machine Learning de classificação, como KNN, SVM, Árvore de Decisão e Regressão Logística.

Ela permite comparar as classificações reais com as previsões realizadas pelo modelo, identificando acertos e erros.

**Como funciona a matriz de confusão:** imagine que treinamos um modelo para identificar se um cliente apresenta alto risco de inadimplência.

O modelo pode acertar ou errar de quatro maneiras diferentes.
![[Pasted image 20261105204845.png]]

**Os quatro resultados possíveis:** 
- *VP — Verdadeiro Positivo (True Positive):* o cliente era de alto risco e o modelo classificou como alto risco.
- *VN — Verdadeiro Negativo (True Negative):* o cliente era de baixo risco e o modelo classificou como baixo risco.
- *FP — Falso Positivo (False Positive):* o cliente era de baixo risco, mas o modelo classificou como alto risco.
- *FN — Falso Negativo (False Negative):* o cliente era de alto risco, mas o modelo classificou como baixo risco.

O falso negativo pode ser especialmente problemático nesse exemplo, porque o banco pode conceder crédito a um cliente de alto risco acreditando que ele é de baixo risco.

Sendo assim, a **matriz de confusão** é uma ferramenta de avaliação de modelos de classificação que compara valores reais e previstos. Ela apresenta quatro resultados: Verdadeiro Positivo (VP), Verdadeiro Negativo (VN), Falso Positivo (FP) e Falso Negativo (FN). A partir deles, calculamos métricas como acurácia, precisão, recall e F1-Score.

|Métrica|O que responde?|
|---|---|
|Acurácia|Quantas previsões o modelo acertou no total?|
|Precisão|Dos que previ como positivos, quantos realmente eram?|
|Recall|Dos que realmente eram positivos, quantos consegui identificar?|
|F1-Score|Qual é o equilíbrio entre precisão e recall?|
